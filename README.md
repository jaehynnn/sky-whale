# 하늘고래의 선착장 — 현재 배포본 소스

2026-10-31에 제작·배포한 프로토타입의 HTML, CSS, JavaScript와 이미지 전체입니다.
주요 실행 파일과 이미지의 내용은 배포본과 동일하며, 전달용으로 폴더 구조만 루트로 옮겼습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 장면 구성, 대사, 버튼 문구, 미션 내용 |
| `style.css` | 색상, 폰트, 크기, 위치, 반응형 스타일, 반복 애니메이션 |
| `story.js` | 스크롤 진행, 대사 표시, 지도 회전·확대, 장면 전환, 수락·거절 동작 |
| `assets/korea.webp` | 대한민국 해안선 지도 |
| `assets/harbor.webp` | 구름 위 선착장 배경 |
| `assets/whale.webp` | 투명 배경 고래 이미지 |
| `.nojekyll` | 정적 파일 호스팅용 빈 파일 |
| `.gitignore` | 로컬 설정·환경 파일 제외 목록 |

## 실행

별도의 Node.js 설치, npm 패키지 설치, 빌드 작업이 필요 없는 정적 웹사이트입니다.
`index.html`을 브라우저로 열어 확인할 수 있습니다.
편집기의 로컬 미리보기 서버를 사용해도 됩니다.

Python이 설치되어 있다면 이 폴더에서 다음 명령으로 실행할 수도 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요.

ZIP을 압축 해제한 뒤, 이 README와 `index.html`이 있는 폴더 안의 파일·폴더를 저장소 루트에 올리세요.
`assets` 폴더와 이미지 파일도 함께 올려야 합니다. GitHub 저장소에 올리는 작업과 웹사이트 호스팅은 별도입니다.

## 수정 위치

- **대사·미션 내용**: `index.html`의 `data-text` 속성 및 `#missions` 영역.
- **화면 디자인**: `style.css`. 아래쪽 `@media` 규칙은 모바일·가로 화면 관련 설정입니다.
- **스크롤에 따른 장면 순서·구간**: `story.js`의 `render()`.
- **첫 대사 표시 속도**: `render()`의 `dialogues[0]._chars.length*36+500` 부분.
- **다른 대사 표시 속도**: `type()`의 `el._chars.length*34+350` 부분.
- **지도 회전·확대 강도**: `mw.style.transform`의 `-23*z`, `1+4.5*z*z` 부분.
- **장면 이동 버튼 위치**: `stops` 배열과 HTML의 `data-jump` 값.
- **거절 버튼 회피**: `dodge()` 및 하단 `pointermove` 이벤트.
- **수락 이후 동작**: `accept.addEventListener('click', ...)`와 `openMissions()`.
- **지도 확대 중심**: CSS의 `transform-origin`, `.map-marker` 위치와 JS의 지도 이동량을 함께 조정합니다.

현재 코드의 속도 상수와 장면 구간 값은 그대로 남겼습니다. 이번 전달 과정에서 디자인이나 동작을 수정하지 않았습니다.

## 참고

기존 Sites 프로젝트의 호스팅 식별자, 저장소 인증 정보, Git 이력은 포함하지 않았습니다.
HTML/CSS/JavaScript와 이미지만으로 실행됩니다.
기존 Sites의 소유자 전용 로그인 화면은 호스팅 서비스가 제공하는 기능이며, 이 코드 자체에는 로그인 기능이 없습니다.
따라서 별도로 호스팅할 때의 접근 범위는 해당 서비스에서 설정해야 합니다.
